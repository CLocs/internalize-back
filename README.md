# Internalize Backend

Local-first semantic knowledge graph API for **MVP 1: The Human Linker**. Capture concepts at different density levels, link them with strictly typed edges, and build your graph by hand.

## Stack

- **Python** · [FastAPI](https://fastapi.tiangolo.com/) · Pydantic
- **Neo4j** (local Desktop instance)
- **Package manager:** [uv](https://docs.astral.sh/uv/)
- **UI:** `index.html` (vanilla JS, Pitch Deck dark theme)

## Prerequisites

1. [Neo4j Desktop](https://neo4j.com/download/) installed
2. [uv](https://docs.astral.sh/uv/getting-started/installation/) installed

```powershell
# Install uv (Windows)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Quick start

```powershell
cd internalize-back

# Install dependencies and create .venv
uv sync

# Configure Neo4j credentials
copy .env.example .env
# Edit .env — set NEO4J_PASSWORD to your actual Neo4j password

# Run the API + Input Pane (hot reload)
uv run uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Open **http://127.0.0.1:8000/** for the Human Linker UI. API docs: **http://127.0.0.1:8000/docs**.

## Connecting Neo4j

The API **starts even if Neo4j is down**. You'll see a warning in the terminal and a red banner in the UI:

> *API is running but Neo4j is unreachable. Start Neo4j Desktop, then refresh.*

That means FastAPI is fine — nothing is listening on Bolt port `7687` yet.

### Step-by-step

1. **Open Neo4j Desktop** and start your local database instance (green **Running** status).
2. **Check the Bolt port** — click your instance → **Details**. Default is `7687`. If yours differs, update `.env`:
   ```
   NEO4J_URI=bolt://127.0.0.1:7687
   ```
3. **Set your password** in `.env`. This must match the password you chose when creating the DB — it is not necessarily `password`:
   ```
   NEO4J_PASSWORD=your_actual_password
   ```
4. **Refresh** http://127.0.0.1:8000/ — the banner should change to *Connected to Neo4j.*

### Verify connectivity

Open **http://127.0.0.1:8000/health** in your browser. You want:

```json
{"status":"ok","neo4j":"connected"}
```

If Neo4j is still down you'll see:

```json
{"status":"degraded","neo4j":"unreachable"}
```

While degraded, the Input Pane loads and relationship types populate, but **Save Node** and **Create Edge** return **503** until Neo4j connects.

### Still stuck?

| Symptom | Fix |
|---------|-----|
| `Connection refused` on port 7687 | Start the DB instance in Neo4j Desktop |
| `Authentication failed` | Wrong `NEO4J_PASSWORD` in `.env` |
| Connects to `localhost` but fails on Windows | Use `127.0.0.1` in `NEO4J_URI`, not `localhost` |
| Changed `.env` but no effect | Restart uvicorn (Ctrl+C, then run again) |

## Environment variables

| Variable | Default | Description |
|----------|---------|-------------|
| `NEO4J_URI` | `bolt://127.0.0.1:7687` | Bolt connection URI (prefer `127.0.0.1` over `localhost` on Windows) |
| `NEO4J_USER` | `neo4j` | Database username |
| `NEO4J_PASSWORD` | `password` | Database password — **change this** |

Copy `.env.example` to `.env` and set your real Neo4j Desktop credentials.

## Data model & ontology

### Nodes (Concepts)

| Property | Type | Description |
|----------|------|-------------|
| `id` | UUID | Generated by the API |
| `title` | string | Short label |
| `content` | string | Raw text at this density level |
| `density_level` | int | `1` = Summary, `2` = Excerpt, `3` = Source |
| `significance` | float | Weight (default `1.0`) |
| `created_at` | timestamp | Set on creation |

### Edges (Relationships)

All edges carry a `strength` property (default `1.0`).

| Type | Axis | Meaning |
|------|------|---------|
| `SUMMARIZES` | Hierarchy | One concept summarizes another |
| `CONTAINS` | Hierarchy | Parent contains child content |
| `SUPPORTS` | Evaluation | Reinforcing evidence |
| `CONTRADICTS` | Evaluation | Conflicting theories |
| `CAUSES` | Logical | Causal dependency |
| `REQUIRES` | Logical | Functional requirement |
| `EXAMPLE_OF` | Logical | Instantiation of a category |
| `FOLLOWS` | Narrative | Sequential / temporal link |

## Input Pane (UI)

Served at **http://127.0.0.1:8000/** — two-column layout:

| Left — Capture Node | Right — Create Semantic Edge |
|---------------------|------------------------------|
| Density level (Source / Excerpt / Summary) | Source node dropdown |
| Title | Relationship type (grouped by axis) |
| Content | Target node dropdown |

Node dropdowns refresh automatically after saving a new node.

## API endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/` | Input Pane (`index.html`) |
| `GET` | `/health` | Neo4j connectivity check |
| `GET` | `/api/nodes` | List concepts (`id`, `title`, `density_level`) |
| `POST` | `/api/nodes` | Create a concept |
| `POST` | `/api/edges` | Create a semantic edge |
| `GET` | `/api/ontology/relationship-types` | Edge types grouped by axis |

### Example: create a node

```bash
curl -X POST http://127.0.0.1:8000/api/nodes \
  -H "Content-Type: application/json" \
  -d "{\"title\": \"System 1\", \"content\": \"Fast, automatic thinking.\", \"density_level\": 1, \"significance\": 1.0}"
```

### Example: create an edge

```bash
curl -X POST http://127.0.0.1:8000/api/edges \
  -H "Content-Type: application/json" \
  -d "{\"source_id\": \"<uuid>\", \"target_id\": \"<uuid>\", \"relationship_type\": \"SUPPORTS\", \"strength\": 1.0}"
```

## Pick up where you left off

When you come back:

1. Start **Neo4j Desktop** → run your DB instance.
2. Confirm `.env` has the correct `NEO4J_PASSWORD`.
3. Start the server:
   ```powershell
   uv run uvicorn main:app --reload --host 127.0.0.1 --port 8000
   ```

4. Open **http://127.0.0.1:8000/** and confirm the green *Connected to Neo4j* banner.
5. Create a node (left column), then link it to another node (right column).

## Development notes

- The app logs a warning on startup if Neo4j is unreachable; data endpoints return 503 until it connects.
- Node IDs are generated in Python (`uuid4`); no APOC plugin required.
- Serve the UI through FastAPI (`GET /`) so API calls stay same-origin.
